# 烟花剧场

在浏览器里点亮烟花、写祝福、用手势互动，观看爱丽丝、凤凰与东方龙的 2D / 3D 演出。
摄像头只在主动开启手势模式后申请，画面在本机处理；声音由第一次点击开启。

## 体验与编辑

- 网页：手机直接打开 [完整版烟花剧场](https://uplinkwolf.cn/fireworks/) 即可观看；「更多 → 关于与下载」提供离线完整版。
- 离线：打开 `release/烟花剧场.html`。完整演出、模型、声音、识别模型和源码均包含在单个文件内。
- 从单文件编辑：在「更多 → 关于与源码」点击「导出可编辑工程」，解压得到本项目。
- 推荐新版 Chrome、Edge、Safari。微信内置浏览器或手机附件预览若不支持 WebGL/摄像头，请在系统浏览器打开。

```sh
npm ci
npm test
npm run build
python3 -m http.server 8080 --directory dist
```

使用 Node.js 24 或更新版本。构建只读本项目文件，不需要历史工作目录、账号或密钥。
将 `dist/` 放到任何静态 HTTPS 主机；离线 HTML 直接分享，不需要服务器。
网站与离线版使用相同的模型、声音和演出代码。网站提供完整体验与离线下载，离线版额外提供可编辑工程导出；GitHub 面向开发者。

## 源码地图

| 位置 | 职责 |
| --- | --- |
| `index.html` / `src/style.css` | 中文界面、无障碍标签与响应式布局 |
| `src/boot.js` | 资源准备与启动 |
| `src/main.js` | 唯一动画时钟、烟花模拟、交互和节目调度 |
| `src/audio.js` | 点击启音、音效声部、配乐交叉淡化、暂停同步 |
| `src/rose-renderer.js` | 可编辑玫瑰网格与花瓣的独立 WebGL 渲染器 |
| `src/shows/` | 凤凰 2D / 3D、东方龙的舞台、镜头、粒子和动作 |
| `src/runtime/` | 网页/离线共用资源接口、流式源码导出 |
| `project.json` | 资源与演出入口清单 |
| `scripts/build.mjs` | 同一份源码生成网页和单文件，输出哈希收据 |
| `tests/` | 生命周期、手势、烟花轨迹、音频与构建契约回归 |

改配色、交互与节目调度从 `src/main.js` 开始，改龙的口颚/爪势从
`src/shows/dragon/attack.js` 开始。修改后重新构建即可生成两种发行版。
渲染器共享主时钟，不自行启动第二个动画循环；资源按演出加载，重播复用已解码数据。

`main.js` 仍承载较多 2D 绘制和节目编排，后续可按稳定的节目接口逐步拆分。
本次优先保持演出一致性，没有为了缩短代码删掉效果或引入框架。

## 体积与保真

模型法线图和 2D 贴图使用像素完全一致的 lossless WebP；节目 WAV 使用 PCM 完全一致的 FLAC。
几何、骨骼、形变、镜头与动画数据保留。内嵌数据使用 gzip；已压缩 MP3 原样保存，确保点击播放的浏览器授权不丢失。
完整配乐、两套高精度模型和本地手势模型仍占据主要体积；网页按需加载，离线版保留全部功能。
